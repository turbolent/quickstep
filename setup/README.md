# Setup.app

Setup is a native OPENSTEP 4.2 AppKit application for installing optional software from the CD after system setup.
It groups packages by category, selects prerequisites, and opens each selected package in Installer.app in dependency order.
Run Setup as root; it launches Installer directly with the same privileges.
Complete each installation, then quit Installer to continue with the next package.
When enabled, it reapplies the PIC kernel fix after User Patch 4.
The package catalog and settings come from `Setup.plist`, generated by `build_cd.py`, so the same executable can be used with different package selections.

## Build

On OPENSTEP 4.2 Intel with Developer Tools and Libraries installed, run from this directory:

```sh
gnumake
gnumake test
```

The app is written to `build/Setup.app`.
Pass that bundle to `build_cd.py` with `--setup-app /path/to/Setup.app`.

To build, test, and package a release archive:

```sh
gnumake release
```

This produces `build/Setup-OPENSTEP-i386.tar`.
